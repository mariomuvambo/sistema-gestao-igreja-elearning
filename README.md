# 📚 Sistema de Gestão de Igreja — E-learning

Projeto de aprendizagem interativa desenvolvido com **Articulate Storyline 360**, com o objetivo de apresentar conceitos e funcionalidades de um sistema digital de gestão de igreja através de uma experiência e-learning.

## 🎯 Objetivo

Demonstrar, através de uma experiência interativa, como uma solução digital pode apoiar a gestão de membros, eventos, grupos, sacramentos e contribuições de uma igreja.

## 🛠️ Tecnologias

* Articulate Storyline 360
* HTML5
* JavaScript
* CSS
* Interações e variáveis do Storyline
* Conteúdo multimédia e elementos interativos

## 📖 Estrutura do projeto

### Cena 1 — Introdução

Apresentação do sistema e contextualização do projeto.

### Cena 2 — [Em desenvolvimento]

Apresentação das funcionalidades e conceitos principais do sistema.

### Próximas cenas

O projeto encontra-se em desenvolvimento. Novas cenas e interações serão adicionadas progressivamente.

## 🚧 Estado do projeto

**Em desenvolvimento**

Este repositório será atualizado à medida que novas cenas, interações, recursos visuais e funcionalidades forem implementados.
